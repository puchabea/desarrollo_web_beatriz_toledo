# Tarea 1 - Desarrollo Web

## Descripción
Esta tarea incluye la implementación de una página HTML con CSS.

## Decisiones tomadas
- Separé para mayor entendimiento entre html, css y js en el documento.

- Para validar creé funciones especificas que permiten distinguir fácilmente que se está validando, por ejemplo, validateName, validateEmail, etc.

- En validateFiles se revisan todas las fotos que envía el usuario, verificando que sean del tipo correcto; validateContact hace algo similar.

- También creé funciones que permiten agregar dinámicamente los archivos e inputs del usuario, estas son agregarFotos y agregarContacto, notar que cuando llegan al límite de fotos permitidas el botón desaparece.

- En el archivo listado.html permití que al clickear en cualquier lugar de la fila se pudiera obtener la información correspondiente.
